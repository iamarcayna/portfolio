    export function useParallaxScene(scene: Ref<HTMLElement | null>) {
      onMounted(() => {
        const mm = gsap.matchMedia();
        mm.add('(prefers-reduced-motion: no-preference)', () => {
          scene.value!.querySelectorAll<HTMLElement>('[data-depth]').forEach((layer) => {
            gsap.to(layer, {
              yPercent: -Number(layer.dataset.depth) * 30,
              ease: 'none',
              scrollTrigger: { trigger: scene.value, start: 'top top', scrub: true },
            });
          });
        });
        onUnmounted(() => mm.revert());
      });
    }

## A first conversation

Vauldex Technologies is a software company in Cebu that builds products for clients in Japan. Its website is the first conversation with prospective clients and engineers, so it has to carry a brand and a fair amount of information: services, delivery process, work, careers and contact. I redesigned and built it, from layout and interaction design to the Vue components, the GSAP animation and the SendGrid contact pipeline.

## Out of the template

The previous site read as a template. It said very little about how the company works and nothing about its character. The brief was to make the site feel like Vauldex (warm, illustrated, a little playful) while staying fast, readable by search engines, and easy for a small team to maintain.

## Scenes, in layers

Each major page opens on an illustrated scene. The illustrations are separated into layers — sky, distant ridges, foreground, characters — and each layer moves at its own rate as the visitor scrolls. The result reads as depth rather than effect.

## Four decisions

- **Transforms only.** Every scroll-linked layer animates `transform` and `opacity`, never layout properties, so the browser can keep scrolling on the compositor.
- **Motion as enhancement.** Content is fully present in the HTML; animations are layered on after load, and reduced-motion preferences remove them entirely.
- **SEO in the markup.** Meta tags, structured data and semantic headings are part of the page templates rather than an afterthought.
- **A boring contact form.** The form posts to a small endpoint that sends through SendGrid. No third-party widget, no tracking embedded in the form.

## Depth without weight

The illustrations are large and the scenes are layered, which is a direct trade against load time. Getting the scenes to feel rich without shipping heavy pages meant careful asset preparation, lazy loading anything below the first scene, and keeping the animation code small enough that it never blocked the first paint.

The other challenge was choreography across breakpoints. A parallax composition tuned for a wide screen falls apart on a phone, so each scene has its own mobile composition rather than a scaled-down version of the desktop one.
