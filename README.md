# Reymond Arcayna — Portfolio

Static portfolio built with Astro, TypeScript, Tailwind CSS v4, GSAP, Three.js, Lenis and MDX. Dark, dev-native, set in Geist.

```bash
npm install
npm run dev       # http://localhost:4321
npm run build     # type-check + static build to dist/
npm run preview
```

## Structure

```
src/
  components/
    hero/          Hero section, intro timeline, sculpture mount
    three/         Three.js sculpture (isolated, lazy-loaded) + build-time SVG poster
    projects/      Work index, project entries, drawn diagrams (visuals/)
    capabilities/  "What I work with"
    about/ experience/ contact/
    navigation/    Header, mobile menu, skip link
    layout/        Shared section heading
    mdx/           Figure / Pair components for case studies
  content/projects/  Case studies (MDX) — schema in src/content.config.ts
  layouts/         BaseLayout (meta, view transitions, motion bootstrap)
  lib/
    site.ts          All non-project content (bio, experience, disciplines, links)
    motion.ts        Declarative GSAP layer: data-reveal / data-parallax
    smooth-scroll.ts Lenis, synced to GSAP's ticker
  styles/global.css  Tokens, type scale, base styles
```

## Adding a project

Create `src/content/projects/<slug>.mdx` with the frontmatter defined in
`src/content.config.ts`. Use `composition: wide | left | right` to vary the layout on
the home index, and either a `cover` image or a drawn `visual`.

## Motion

Components never import GSAP directly for simple reveals. Add attributes instead:

```html
<h2 data-reveal="lines">…</h2>
<div data-reveal="clip"><img … /></div>
<div data-parallax="0.1">…</div>
```

All motion is disabled under `prefers-reduced-motion`. Smooth scrolling is only enabled
for fine pointers.

## The particle portrait

`src/components/three/portrait.ts` renders ~9k particles sampled from the portrait
photo. The data lives in `public/face-points.bin` and is generated by
`scripts/build-face-points.py` (OpenCV GrabCut segmentation + tone and edge sampling);
re-run it only when the photo changes. Particles assemble on load, part around the
pointer or a finger, and drift apart on scroll. It pauses off-screen, caps DPR, drops to
a lighter 30fps scene on phones and low-core devices, and falls back to a 2D canvas
drawing of the same points without WebGL.

## Developer details

- `⌘K` / `Ctrl K` / `/` opens a command palette (`CommandPalette.astro`).
- The contact section has a small working terminal (`help`, `email`, `socials`, …).
- Project code excerpts live in each case study's frontmatter (`snippet`) and are
  highlighted at build time with Shiki — no client JS.
